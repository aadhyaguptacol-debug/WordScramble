# 🧩 Word Scramble Game

An interactive and engaging **Word Scramble** game where players unscramble mixed-up letters to find the correct words. Built with clean, modern code, this project offers a fun way to test vocabulary, quick thinking, and spelling skills!

---

## ✨ Features

* **Dynamic Word Generation:** Randomly selects words from a comprehensive word list for endless replayability.
* **Interactive Gameplay:** Simple user interface allowing players to type their guesses and check answers instantly.
* **Score Tracking:** Keeps track of correct guesses, streaks, or scores in real time.
* **Hints System:** Option to get hints if a word proves too difficult.
* **Responsive Design:** Looks and plays great across desktop computers, tablets, and mobile devices.
